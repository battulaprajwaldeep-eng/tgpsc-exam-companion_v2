How to use this before the exam

Read the hook once, close the card, answer its recall prompt aloud or mentally, then solve 3–5 fresh MCQs on that topic. Revisit missed cards the next day and again after 3 days.

Do not memorise only the hook. In numerical and programming questions, practise applying the rule to new values and cases.
