Memory Tricks Lab

Short mental pictures, exam traps and active recall. These are memory aids—not substitutes for understanding or the official syllabus.

Use this 6-step memory cycle

1 · UnderstandKnow why the rule works.
2 · VisualiseTurn it into a scene or diagram.
3 · RememberAttach one short hook.
4 · TrapNotice the common wrong option.
5 · RecallAnswer without looking.
6 · ReinforceRetry later with a new question.

Topic memory cards

How to use this before the exam

Read the hook once, close the card, answer its recall prompt aloud or mentally, then solve 3–5 fresh MCQs on that topic. Revisit missed cards the next day and again after 3 days.

Do not memorise only the hook. In numerical and programming questions, practise applying the rule to new values and cases.
