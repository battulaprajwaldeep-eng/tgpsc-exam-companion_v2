Accepted question format

{
  "id": "P2-OS-NEW-001",
  "paper": 2,
  "topicId": "p2-10",
  "topic": "Operating Systems",
  "subtopic": "Deadlocks",
  "difficulty": "moderate",
  "stem": "Question text...",
  "options": ["A", "B", "C", "D"],
  "answer": 1,
  "explanations": [
    "Why A is incorrect.",
    "Correct. Why B is correct.",
    "Why C is incorrect.",
    "Why D is incorrect."
  ],
  "basis": "Official Paper II syllabus: Operating Systems."
}

Answer is a zero-based index: 0=A, 1=B, 2=C, 3=D. Paper must be 1 or 2. Similarity warnings are advisory only; they are never silently discarded.
